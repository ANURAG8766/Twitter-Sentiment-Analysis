# Twitter Sentiment Analysis

## Overview

This project uses Natural Language Processing (NLP) and Machine Learning to classify tweets as Positive or Negative.

The model is trained on the Sentiment140 dataset containing 1.6 million real-world tweets.

## Features

- Real-time sentiment prediction
- TF-IDF vectorization
- Logistic Regression classifier
- Model persistence using Joblib
- Classification report generation
- Trained on 1.6 million tweets

## Technologies Used

- Python
- Pandas
- Scikit-Learn
- NLP
- TF-IDF
- Logistic Regression
- Joblib

## Dataset

Sentiment140 Dataset

Size: 1.6 Million Tweets

## Results

- Accuracy: 80.17%
- Precision: 0.80
- Recall: 0.80
- F1 Score: 0.80
